L1 · 다락 지붕 + 창 하나

브랜드 문서 제안

'대표 자리에 불이 켜져 있다' — 창 하나만 인주색.

L2 · 지붕 아래 셋

지붕(loft) 아래 크기가 다른 셋(crew). 셋 중 하나만 인주색 = 대표.

깃허브 README 머리 — 밝게 · 어둡게(깃허브 화면 밝기에 따라 그림이 바뀌게 <picture> 두 벌)

집 · 부동산 앱처럼 보이지 않게

  • 벽 · 문 · 굴뚝을 그리지 않았어요. 집 아이콘은 '지붕 + 벽 + 문' 세 개가 모여야 집으로 읽혀요. 여섯 시안 모두 지붕(또는 지붕 선)만 있고 벽 · 문이 없어요.
  • 지붕 아래가 '사람 · 불빛'이에요. 부동산 앱은 건물 모양 자체가 주인공인데, 여기는 지붕 아래 불 켜진 창(L1) 또는 팀(L2)이 주인공이에요.
  • 비율: 지붕은 낮고 넓게(물매 약 35–40°), 기운 지붕(외쪽 지붕)은 아예 좌우가 다르게 — 뾰족한 오각형 집 모양을 피했어요.
  • 색: 검정 · 흰색 + 인주색 한 점. 부동산 앱이 흔히 쓰는 파랑 · 초록 · 주황 지붕을 쓰지 않아요.

- 결정 80 안전장치는 자리만 옮겼다: 등급 세 가지는 줄 앞 표시 + 낱말, 밖으로는 시트 안 ① 원문 확인 → ② 승인(연습 게시 기본), 승인 내용 고정 지문, 고쳐 주세요의 이번만 / 앞으로도는 접어서, 인계 메모는 접힌 줄, 작업 기록은 결과물 · 업무 시트, 사용 한도 '계속할까요'는 질문으로.

## 5. 화면별 결정 기록
### S1 사무실 메인 — 결정 44
프로토타입: `prototype/ui/s1-office/` (1–3안 비교 + 채택안)
- **구조:** 좌측 아이콘 레일(5메뉴) / 화면 전체 2D 사무실 / 좌상단 회차 제목 / 우상단 상태 칩(단계·한도·실행 환경·전체 일시정지) / 우측 상단 결정 카드 / 하단 도크.
- **하단 도크:** 주간 7단계 흐름(조사→기획→작성→이미지→검수→확인→게시). 단계마다 담당자와 상태(완료/진행 중/대기/한도 대기/내 확인 필요)를 표시한다. 단계를 누르면 담당 직원 카드가 열린다. 같은 줄에 최근 활동 한 줄을 두고, 펼치면 활동 전체를 보여준다.
- **직원 카드:** 직원을 누르면 옆의 여유 있는 쪽에 떠 있는 카드가 열린다. 탭은 지금 하는 일(단계·대기 이유) / 대화 / 결과물 / 배운 것(숙련도, 출처, 추정 표시).
- **대기 이유 문구:** 인계는 수락해야 완료, 사용자 확인 전 게시 없음, 한도 도달 시 리셋 후 자동 재개·자동 전환 없음을 상태마다 설명한다.
- **연결 끊김:** 사무실을 회색으로 정지하고 마지막 확인 시각을 배너로 표시한다. **동작 줄이기:** 걷기 없이 이동하고 상태 문구는 동일하게 유지한다.
- **남은 과제:** 작은 화면용 목록 보기.
- **(2026-10-08 갱신, 결정 80 · D4)** **되묻는 중 · 잠듦이 가장 눈에 띄게** — 3D 이름표 위에 큰 표시('? 되묻는 중' 금색 · 살짝 위아래로, 'z 잠듦' 짙은 남보라), 이름표 테두리도 같은 색, 휴대폰에서도 숨기지 않는다(같은 말을 하는 이름표 알약은 숨김). 자세: 되묻는 중 = 손 들기, 잠듦 = 느리게 숨 쉬며 고개 숙이기(모델 · 조명 추가 없음). 상단 칩 '? 되묻는 중 n' · 'z 잠든 업무 n'(결정함으로), 도크 · 회차 보드 칸도 같은 색 + '❓ 되묻는 중' · '💤 잠듦' 글자. 'task_asked' 이벤트면 묻는 직원 머리 위에 질문 말풍선(서류는 들고 가지 않음), 'task_answered'면 답한 직원에게 짧게. **서류 들고 걷기는 지금처럼 실제 인계(`handoff_accepted`) · 복귀 요약의 실제 인계 기록에만.** 결정 카드 줄마다 등급 모양. 칸 색 · 설명은 서버 값 그대로(`flow[].state` · `flowBlocks[].state`의 `asked` · `asleep`, 설명 '되묻는 중 — <질문 앞부분>' · '잠듦 — 한도 <업무 · 직원 주간 · 사무실 주간>'). 블록 띠 순서도 서버 그대로 — 그 블록이 내 확인을 기다리면 '내 확인'이 앞선다(2026-10-08, 화면 추론 `withAgentStates`는 뺐다).
- **(2026-10-05 갱신, P2 결정 6)** 블록 회차면 도크와 3D 회차 보드가 7단계 대신 **이번 주 블록 띠**(블록마다 담당 · 상태 · 확인 대기, 보드 제목 옆 '블록 n/m 끝'), 상단 칩도 '블록 n/m 끝'. 콘텐츠 운영만 있는 회차 · 옛 사무실은 7단계 그대로.
- **(2026-10-03 갱신, 결정 63·65–68)** 가운데 사무실은 3D. 위쪽에 실적 자원 바(🔎 · ✍️ · 🎨 · 🤝), 왼쪽 아래 층 안내판(단계 · 정원 · 다음 단계 조건)과 배치 모드 버튼. 점선 칸(빈 부지)을 누르면 짓기 카드, 설계도가 없으면 '공간 설계 부탁하기' 카드. 물건을 꾹 누르면 배치 모드. 직원을 누르면 확대 + 카드, 닫으면 확대 전 시점으로.
- **(2026-10-04 갱신, 사용자 제안)** 배경은 컴퓨터 시계의 시간대를 따른다(새벽 · 아침 · 오후 · 저녁 · 밤 — 하늘 · 창밖 도시 · 해 방향 · 실내 조명). 하늘이 어두우면 회차 제목을 밝은 글자로. 떠 있는 카드(빈 부지 · 새 방 요청 · 공사장 · 방 이름표 · 시설 표지)는 캐릭터 이름표처럼 늘 카메라를 본다. 점검은 `?hour=5` · `?hour=demo`.
- **(2026-10-04 갱신, 결정 75)** 사무실은 **도시 블록 한가운데 건물**이고, 카메라는 **원근 없는 아이소메트릭**이다. 끌기 = 이동 · 휠 = 커서 쪽 확대 · 축소 · 오른쪽 끌기 / ↺↻ / Q·E = 90° 회전(대각선 4방향에 맞춤). 왼쪽 가운데 **줌 사다리**(도시 · 동네 · 건물 · 방 · 책상)로 단계를 바로 고르고, 줌 단계마다 보이는 정보가 다르다 — 책상: 이름표 아래 지금 하는 일 · 방: 이름표 · 카드 · 건물: 지붕이 닫히고(지붕 열기의 반대) 이름표 대신 우리 건물 표지(회사 · Lv · 직원 · 일하는 중 · 결재, 누르면 안으로) · 동네 · 도시: 도시가 공기색으로 녹아드는 지도. 방 보기에선 카메라 쪽 벽만 낮아지고 건물 가까운 나무는 숨는다. 왼쪽 아래 **미니 화면**(다른 방 실시간, 최대 3개, 누르면 그 방으로 — 1000px 이하에선 숨김), **🎥 자동**(켜 두면 손을 뗀 지 9초 뒤부터 실제 이벤트를 따라가는 카메라, 만지면 멈춤). 켜고 끈 것은 이 브라우저에 기억한다. 코드: `web/js/office3d/stage.js`(카메라) · `city.js` · `exterior.js` · `pip.js` · `director.js`, 스타일 `web/css/office3d.css`.

### S8 회사 지식 · 성과 — 결정 53
프로토타입: `prototype/ui/s8-company/` (1–3안 비교 + 채택안)

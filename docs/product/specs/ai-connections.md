# Agent Office — AI 제공 및 개인 연결

> 2026-10-01 통합 메모: "서비스 제공 AI 기본"은 후속 버전으로 미뤄졌다(결정 25). R0/R1은 사용자 구독(Codex 중심, Claude는 Anthropic 문의 후 결정 — 결정 34). 2026-10-01 재확인한 정책은 [publishing.md](publishing.md) §3.

상태: 기본 제공 AI와 개인 연결 방향은 사용자 확정. 구독 계정 연결은 핵심 요구사항으로 유지한다. 제공자별 실제 지원 경로와 배포 조건은 공식 근거에 따라 구분하며 아직 구현하지 않았다.

## 사용자 결정
- 처음에는 서비스가 제공하는 AI로 시작할 수 있어야 한다.
- 원하는 사용자는 개인 API 키도 연결할 수 있다.
- 개인 연결은 API 키만을 뜻하지 않는다. Claude·ChatGPT 구독으로 로그인해 이용하는 경험을 주요 대상으로 다룬다.
- 참고 서비스는 Hermes Agent와 Aside이다.
- 로컬, 개인 VPS, 관리형 서버라는 실행 장소 선택과 AI 이용 방식은 별도 개념이다.

## 설정 구조 제안
`설정 → AI 연결`을 두고 다음 세 종류를 구분한다.
| 종류 | 사용자 행동 | 비용/한도 표시 |
| --- | --- | --- |
| 기본 제공 AI | 별도 외부 계정 없이 시작 | Agent Office에서 제공한 사용량 및 요금 정책 |
| 개인 구독 연결 | 지원되는 공식 로그인 경로로 본인의 계정 연결 | 해당 구독에서 제공되는 사용 상태와 제한 |
| 개인 API 키 | API 제공자 선택 후 자신의 키 등록 | 개인 API 사용량, 확인 가능한 비용 및 제한 |

Claude·ChatGPT 연결은 사용 가능한 계정/실행 환경에서만 활성화한다. 모든 구독 계정이 임의의 모델 API 사용권이나 무제한 백그라운드 사용권을 제공한다고 표시하지 않는다.

## 연결 항목 상세 제안
- 제공자와 연결 방식(구독/API 키/서비스 제공).
- 계정 표시명, 연결 상태, 연결이 유효한 실행 환경.
- 실제 사용할 수 있는 모델/기능. 계정이 지원하지 않는 모델을 선택지로 활성화하지 않는다.
- 사용 중인 직원과 업무.
- 제공자가 노출하는 범위의 사용 한도/갱신 시각. 정보가 없으면 추정치를 확정값처럼 표시하지 않는다.
- 기본 연결로 지정, 재로그인, 연결 해제.

API 키는 입력 후 전체 값을 다시 보여주지 않는다. 구독 로그인은 제공자가 지원하는 인증 흐름을 사용하며, 사용자의 브라우저 쿠키나 기존 앱 비밀정보 추출을 연결 방식으로 삼지 않는다.

## 직원 배정 — 제안
- 기본값은 사무실의 기본 AI 연결을 사용한다.
- 고급 설정에서 직원별로 다른 지원 연결을 지정하는 방안을 제공한다.
- 역할/목표/프로젝트 자료는 Agent Office가 유지하는 직원 맥락이다. 연결을 바꾸면 필요한 맥락을 전달하되 서로 다른 제공자의 내부 세션을 그대로 옮길 수 있다고 약속하지 않는다.
- 모델을 바꿔도 외부 게시/발송/결제/추가 고용의 사용자 확인 정책은 유지한다.

## 한도와 전환 — 제안
- 여러 직원이 같은 개인 구독을 사용하면 계정의 사용 한도를 함께 고려한다. 직원 수만큼 독립적인 구독 한도가 생긴다고 표시하지 않는다.
- 한도 도달, 연결 만료, 일시 오류를 구분한다.
- 한도에 도달하면 관련 업무를 대기시키고, 가능한 경우 재개 시점을 보여준다.
- 다른 연결로 전환할 때 비용과 데이터 전달 대상이 달라질 수 있음을 보여준다.
- 비용을 발생시키는 대체 연결로의 무단 자동 전환은 기본값으로 삼지 않는다. 사전 허용/예산 기반 전환은 후속 정책으로 결정한다.
- 24시간 실행 환경 제공과 AI의 24시간 무제한 사용을 구분한다.

## 서비스 제공 AI의 운영 원칙 — 제안
서비스 제공 AI의 정산/계약과 사용자의 개인 연결은 분리한다. 서비스 제공 AI를 개인 소비자 구독 하나로 여러 고객에게 재판매하는 구조로 가정하지 않는다. 구체적인 공급자, 계약 형태, 모델, 요금은 아직 미정이다.

## 제공자별 조사 근거
### ChatGPT / Codex — 확인된 공식 경로
2026-09-27 조회한 OpenAI 문서에 Codex app-server의 ChatGPT 브라우저 로그인, 디바이스 코드 로그인, 로그인 상태/사용 한도 조회가 명시돼 있다. 이것은 Codex 기반 실행 경로의 근거이며 일반 OpenAI API 호출에 구독 크레딧을 사용할 수 있다는 뜻은 아니다.
- https://learn.chatgpt.com/docs/auth
- https://learn.chatgpt.com/docs/app-server#auth-endpoints

환경별 운영과 계정별 실제 지원 범위는 구현 계획에서 별도 검증한다. 공식 프로토콜 일부가 실험적이므로 구현 시 버전과 안정성을 확인한다.

### Aside — 확인된 UX 참고
Aside Computer Inc.의 Aside AI Browser 공식 문서는 `Settings → Models → Providers`에서 자체 제공(Aside), 구독(Subscription), API 키(API)를 구분한다. ChatGPT와 Claude 구독의 OAuth 로그인 흐름 및 지원되는 구독의 사용량 표시를 설명한다. Agent Office의 세 종류 연결 UX에 직접 참고한다.
- https://docs.aside.com/help/ai

Aside 공개 문서만으로 Claude 연동에 대한 제공자 승인 유무, 내부 인증 구현, 실행 장소를 확인하지 못했다. 이를 Agent Office에 동일한 이용 권한이 있다는 근거로 삼지 않는다.

### Hermes Agent — 구현 참고와 경계
Hermes upstream은 OpenAI Codex/ChatGPT 로그인과 선택적인 공식 Codex app-server 실행 경로를 문서화한다. 개인 구독 로그인 및 장기 실행 환경의 연결 상태를 다루는 참고 사례다.
- https://github.com/NousResearch/hermes-agent/blob/f039f028f2bd5c6e2131b4ffaa4b200c81db68a3/website/docs/integrations/providers.md
- https://github.com/NousResearch/hermes-agent/blob/f039f028f2bd5c6e2131b4ffaa4b200c81db68a3/website/docs/user-guide/features/codex-app-server-runtime.md

Hermes의 인증 구현이나 다른 CLI의 로그인 정보를 사용하는 기능은 해당 제공자의 제3자 제품 허용 여부와 별도다. 그 동작을 그대로 채택한다고 결정하지 않았다.

### Claude — 제공 조건 확인 필요
2026-09-27 확인한 Anthropic 공식 Agent SDK 문서는 사전 승인 없이 제3자 개발자가 제품에 Claude.ai 로그인 또는 구독 사용 한도를 제공하는 것을 허용하지 않는다고 명시한다. Claude Code 자체의 구독 로그인 지원과 Agent Office의 상용 구독 연결 제공 권한을 구분한다. CLI를 호출하는 방식만으로 이 조건이 충족된다고 판단하지 않는다.
- https://code.claude.com/docs/en/agent-sdk/overview
- https://code.claude.com/docs/en/agent-sdk/quickstart
- https://code.claude.com/docs/en/authentication

Claude 구독 연결은 사용자 요구사항으로 유지하고, 공식 승인/지원 프로그램 확인을 제공 전 조건으로 추적한다. 확인 전에는 지원 완료/출시 가능으로 표시하지 않는다. API 키 연결과 서비스 제공 AI는 별도 경로로 기획한다. 공개된 제3자 연동 사례만으로 승인 여부를 추정하지 않는다.

## 완료 기준 후보
1. 개인 계정을 연결하지 않아도 기본 제공 AI로 첫 팀을 시작할 수 있다.
2. 지원되는 개인 구독 로그인과 API 키 연결을 다른 경로로 설정할 수 있다.
3. 각 연결의 계정/상태/유효 실행 환경을 확인할 수 있다.
4. 연결 변경 또는 한도 도달이 직원 업무 상태에 반영되고, 무단 추가 과금으로 이어지지 않는다.
5. 제공자별 허용/지원 경로에서 실제 결과물을 만드는 흐름을 검증한다. 미지원 경로를 연결 성공으로 표시하지 않는다.

## 미결정 사항
- Claude 개인 구독의 제3자 제공 승인/지원 조건, ChatGPT/Codex 경로의 실제 통합 검증, 두 제공자의 관리형 환경 이용 조건.
- 기본 제공 모델/요금/사용 한도, 개인 API 키 지원 제공자 목록.
- 직원별 연결 선택 및 대체 연결의 세부 UX.

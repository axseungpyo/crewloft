# 사무실 캐릭터 컨셉 기획 (진행 중)

2026-10-03 재시작. 2D 일러스트(결정 14·15)와 3D 시안(`prototype/concept3d/`), 캐릭터 시안(`prototype/character3d/`)은 참고 자료로 두고, 캐릭터 컨셉을 처음부터 다시 정한다.

## 이미 정해진 전제 (다른 결정에서)
- 대상: 1인 창업자·프리랜서·1인 크리에이터 (결정 19)
- 채용은 한 명씩, 매니저부터 (결정 54·56)
- 외형·이름·말투·성향은 커스터마이징한다 — 스타일 설정이며 능력치가 아니다 (결정 55)
- 성장은 실제 기록에서만 보여준다 — 가짜 게임 수치 금지 (결정 21·22)
- 사무실 모션은 이벤트 기록에서만 나온다 (결정 37)

## 기획 순서
1. 캐릭터는 사용자에게 어떤 존재인가 — **정함**
2. 어떤 모습의 존재인가 — **정함**
3. 세계관: 왜 이 사무실에 있나 — **정함**
4. 체계: 직무·직급·성장이 어떻게 보이나 — 성장 표현 **정함**, 펫 시스템 범위·부화 방식 검토 중
5. 디자인 규칙: 실루엣·얼굴·색·소품·2D/3D
6. 시안 → 선택

## 직무 상징 초안 (시안용 — 조정 가능)
직급이 오를수록 같은 상징이 청동 → 은 → 금 → 금 + 장식으로 바뀐다(장비가 생김, C4).

| 상징 | 신화 | 직무 |
|---|---|---|
| 깃털 장식 투구 | 아테나(지혜·전략) | 매니저 — 기획·전략 |
| 은빛 초승달 + 작은 활 | 아르테미스(찾아내기) | 리서처 — 조사 |
| 월계관 + 깃펜 | 칼리오페(서사의 뮤즈) | 작가 — 글 |
| 무지개 고리 | 이리스(무지개 전령) | 디자이너 — 색·이미지 |
| 날개 헬멧 | 헤르메스(전령) | 게시·전달 |
| 저울 | 테미스(공정) | 검수·품질 |
| 모래시계 | 크로노스(시간) | 일정 관리 |
| 소라 나팔 | 트리톤(알림) | 홍보·마케팅 |

## 시안 (2026-10-03)
- 보드: `prototype/messengers/` — `node prototype/serve.mjs` 후 http://127.0.0.1:4318/messengers/
- 같은 전령 넷을 세 방식으로: ① 전부 3D(`m3d/cast.js`) ② 전부 2D(`m2d/cast.js`, 사옥 단면 사무실 `office2d.js`) ③ 2D 캐릭터 + 3D 사무실(HD-2D, `hd2d.js`)
- 방식마다 라인업 · 일하는 장면 · 작은 크기(떠 있는 당번 전령, 휴대폰 알림, 96/48/24px 아이콘)를 보여준다. 비교 탭에 캐스트 표, 점수, 직무 상징 도감(8종 × 직급 4단계)이 있다.
- 제안(사용자 확인 전): ③ HD-2D. 캐릭터가 2D라 AI 생성 부화와 잘 맞고, 알림·위젯까지 같은 그림으로 이어지며, 사무실은 3D 공간감을 준다.

## 검토 중: 펫 시스템 느낌 (사용자 제안, 2026-10-03)
- **Claude Code `/buddy`** (2026-04 만우절 이벤트): 터미널 입력창 옆 ASCII 펫. 계정마다 종(18종)·희귀도(5단계)가 정해지고, 처음 부화할 때 성격이 생기며 대화에 말풍선으로 반응한다.
- **Codex 펫:** 앱 위에 떠 있는 애니메이션 동반자. 에이전트가 일하는 중·끝남·입력 필요를 알려준다. 기본 8종이 있고 `/hatch`로 AI가 원하는 모습을 만들어 준다.
- **가져올 것:** 부화(채용 의식), 처음 정해지는 개성, 이벤트에 대한 반응, 떠 있는 상태 알림(전령 세계관과 맞음), 설명으로 모습 만들기.
- **피할 것:** 무작위 능력치·희귀도 뽑기(가짜 수치 — 결정 21·22와 충돌), 방치하면 아프거나 슬퍼지는 돌봄 의무(업무 도구에 죄책감은 맞지 않음).

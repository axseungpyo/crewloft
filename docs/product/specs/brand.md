## 2. 브랜드 핵심

### 2-1. 누구에게, 무엇을 약속하나
- **대상:** 혼자 또는 몇 명이 창업을 막 시작하는 사람(PRD §2, 결정 73). 사업 종류는 무엇이든, 기술은 몰라도 된다.
- **약속(한 문장):** **"AI 팀이 일하고, 대표님은 확인하고 결정해요. 회사는 해낸 만큼 자라요."**
  - 일한다 = 조사 · 계획 · 준비를 나눠 맡음(결정 73)
  - 확인 · 결정 = 밖으로 나가는 일은 대표 확인 없이 없음(결정 8)
  - 자란다 = 실제 실적으로만(결정 21 · 22 · 66–68), 가짜 수치 없음
- **화면의 세 층:** ① **무대**(3D 사무실 — 팀이 일하는 게 보임) ② **도구**(2D 크롬 — 조용하고 명료) ③ **대표 몫**(한 가지 색 — 확인 · 결정할 것만 빛남).

### 2-2. 성격 — 네 낱말
| 낱말 | 뜻 | 화면에서 |
| --- | --- | --- |
| **대담한** | 작게 시작해도 회사답게 | 굵은 제목, 대담한 3D 마스코트, 망설이지 않는 한 가지 강조색 |
| **명료한** | 지금 무엇을 하면 되는지 바로 | 화면마다 주 행동 하나, 상태는 아이콘 + 낱말 + 색, 내부 용어 없음 |
| **믿음직한** | 맡겨도 된다 | 무채색 도구, 정직한 숫자(가짜 AI · 연습 게시를 숨기지 않음), 과장 없는 말 |
| **자라는** | 해낸 만큼 커진다 | 성장은 황동색 하나로만, 레벨 · 자원 · 새 방이 실제 기록에서 생김 |

### 2-3. 하지 말 것
- **아기자기 · 치비 · 파스텔 · 장난감 느낌**(결정 63 · 64, 메모): 둥글둥글한 2D 일러스트, 메모지 · 테이프 · 스티커 장식, 이모지 아이콘, 반짝이 · 폭죽 효과.
- 마스코트를 **사람처럼**(사람 얼굴 · 입 · 사람 옷) 그리기 — 'AI다운 새로운 존재'(characters C1). 기준: 둥근 대담한 실루엣 · 점 눈 · 입 없음 · 비닐 같은 3D 마감 · 채도 높되 어른스러운 색.
- **가짜 게임 수치**(경험치 막대를 위한 숫자, 타이머로 기다리게 하기, 유료 뽑기).
- 색만으로 상태 알리기, 한 화면에 강조색 두 개 이상.
- 내부 용어를 그대로(드라이런 · fake 같은 개발 낱말), 느낌표 · 과장('완벽한', '혁신적인'). 창업자에게 익숙한 영어 · 약어(SEO · SNS · Lv 등)는 써도 된다(2026-10-08 사용자 확인).
- 2D 화면에서 비유 이름을 기능 이름 대신 쓰기(결정 B2 제안 ①).

### 3-1. 추천: B · 선명한 본사
1. **약속이 색 하나로 보인다.** 인주색(도장 색) = 대표가 확인 · 결정할 것. 왼쪽 막대 배지 · 결정함 버튼 · 결과물 확인 칩 · 3D 결재함 위 숫자가 모두 같은 색이라 "어디서든 붉은 것 = 내 차례".
2. **마스코트가 주인공이 된다.** 무대가 무채색이라 종 · 색이 자유로운 마스코트(characters C2 · C8)가 한 회사처럼 묶이고, 대담한 비닐 마감(메모)과 부딪히지 않는다.
3. **기준이 가장 단순하다.** 글꼴 하나, 강조색 하나(+ 성장 황동), 모서리 셋. 지금의 104색 · 24크기 · 14모서리를 줄이기 가장 쉽다.
4. **위험과 대응:** 붉은색 ≠ 문제 — 문제는 라즈베리 #C8234F + ⚠ 아이콘 + 낱말('다시 연결 필요')로 따로, 대표 몫은 문서 · 확인 아이콘과 함께. 차가움은 해요체 말투 · 마스코트 · 시간대 조명으로 채운다.

### 3-3. 아이콘 체계
- **이모지를 쓰지 않는다**(사용자 글 · 대화 속 이모지는 예외). 24 그리드, 2px 선, 둥근 끝 · 이음, 채움 없음. 지금 위치(왼쪽 막대)만 연한 채움.
- 한 파일에 SVG 묶음(직접 그리거나 Lucide 같은 오픈 라이선스 세트를 골라 고정 — 라이선스는 THIRD_PARTY_NOTICES에). 견본의 20개로 시작: 사무실 · 결정함 · 일 · 회사 · 설정 · 확인(문서) · 체크 · 경고 · 멈춤 · 잠금 · 대화 · 시계 · 재생 · 도시 · 방 · 책상, 자원 신뢰(방패) · 원고(펜) · 인사이트(전구) · 디자인(팔레트).
- 지금 이모지 39종 → 아이콘 이름 대응표는 2단계에서 만든다. 서버가 주는 자원 아이콘(`/api/meta`의 🤝 ✍ 등)은 **아이콘 이름 키**를 함께 주도록 기술 몫 제안.

### 3-4. 3D와 2D가 한 결로 보이는 규칙
1. **같은 토큰에서 재질을 뽑는다.** 벽 = `--surface`, 바닥 = `--bg`보다 한 단계 밝은 콘크리트, 가구 = `--ink` 계열 짙은 회색. 3D 코드는 색 상수를 직접 갖지 않고 토큰 표(재질 팔레트 하나)에서 읽는다.
2. **채도는 두 곳에만.** ① 마스코트(비닐 광택, 종 · 색 자유) ② 기능 시설 한 점씩 — 결재함 = 인주색, 레벨 · 시설 Lv 표 = 황동. 나머지 소품은 무채색 + 식물 초록 한 가지.
3. **떠 있는 2D는 2D 컴포넌트 그대로.** 이름표 · 말풍선 · 결재 숫자 · 시설 카드는 앱의 알약 · 카드와 같은 면 색 · 선 · 모서리 · 글꼴(결정 75의 '카메라를 보는 표지' 유지).
4. **무광 기본, 광택은 마스코트만.** 건물 재질은 무광(거칠기 높게), 마스코트만 비닐 반사 — 눈이 자연스럽게 직원에게 간다.
5. **조명이 테마를 따른다.** 시간대(결정 75)는 3D 조명 · 하늘만 바꾸고, 2D 크롬은 B3 결정을 따른다. 밤 3D + 밝은 크롬도 어색하지 않게 떠 있는 카드엔 늘 `--surface`를 쓴다.
6. **홈과 앱의 3D를 같은 재질로.** 지금 홈(나무 바닥 · 하늘색)과 앱(흰 바닥)이 다르다 → 같은 팔레트, 홈은 사업별 예시 공간만 다르게.
7. **사무실 화면의 떠 있는 무리는 셋까지.** 위 줄(제목 · 상태 · 자원) · 오른쪽 '확인할 것'(대표 몫) · 아래 도크(이번 주 블록). 줌 · 회전 · 자동 카메라는 한 묶음 도구 막대로, '필요의 방' · 레벨 카드는 필요할 때 여는 시트로.

### 3-5. 어두운 모드
- B의 어두운 토큰은 위 표. 그래파이트 바탕, 창은 호박빛, **결재함의 인주색이 가장 밝은 점** — 어두운 화면에서도 '내 차례'가 한눈에.
- 결과물 확인(문서 · 표)은 어두운 모드에서도 읽기 우선 — 본문 대비 7 이상(`--ink` on `--surface`).

## 4. 말투 · 문구 원칙

1. **해요체, 대표님께.** 사용자는 '대표님', 직원은 이름으로 주어를 세운다("하나가 체크리스트를 정리했어요").
2. **어려운 말 대신 하는 일로.** 내부 용어는 화면에 내지 않는다.
   | 지금 | 바꿈 |
   | --- | --- |
   | 드라이런 | 연습 게시 |
   | 가짜 AI(로컬 확인용) | 견본 AI |
   | 회차 | 이번 주 일 (회차는 기획 · 코드 이름으로만) |
   | 블록 | 할 일 묶음 → 화면에선 그 일의 이름("가격 · 원가 계산") |
   | Lv 2 | 레벨 2 |
   | 내 개입 | 내가 처리한 것 |
   | 열쇠함 · 전력실 · 우편함(2D) | 연결된 앱 · AI 연결 · 알림 (비유는 3D 시설 이름으로만) |
3. **숫자 규칙.** 숫자와 단위는 붙인다(3건 · 2명 · 1분 30초). 0이면 '아직 없음'. 분수는 '7단계 중 2단계'(2/7 금지 — 표 안 좁은 칸만 예외). 비율은 무엇의 %인지 쓴다('한도 19% 썼어요'). 돈은 쉼표 + 원(1,280원). 숫자는 고정폭.
4. **상태 낱말 여섯 개로 고정.** 시작 전 · 일하는 중 · 대표 확인 · 끝 · 멈춤 · 문제 — 늘 아이콘 + 낱말 + 색. '완료 · 작업 완료 · 끝'처럼 같은 상태를 다르게 부르지 않는다.
5. **버튼은 동사로 끝낸다**('결정함에서 보기', '확정', '수정 요청'). 오류는 '무슨 일 + 다음 행동'('Slack 연결이 끊겼어요 — 설정에서 다시 연결').
6. **정직하게.** 가짜 AI · 연습 게시 · 임시값은 숨기지 않고 짧게 알린다. 느낌표 · 과장 없이.

### 6-3. P2 화면 2차와 겹치는 부분
P2 화면 2차(같은 워크트리, [p2-blocks-plan](../plans/p2-blocks-plan.md) §4)가 고치는 중인 파일과 이 기획의 1–3단계가 겹친다.

| P2 2차 일 | 겹치는 파일(지금 수정 중) | 이 기획과의 관계 |
| --- | --- | --- |
| D2 메뉴 '일' · 문서함 · 캘린더 | `screens/work.js`(content.js에서 옮김) · `calendar.js` · `web/css/work.css` | 3단계 '일'과 같은 화면 — P2 2차가 구조를 끝낸 뒤 스타일만 덮는다 |
| D3 내 할 일 · 사이드바 배지 | `screens/todos.js` · `decisions.js` · `main.js` · `shell.css` | 배지(D8) · 왼쪽 막대 아이콘이 같은 자리 — 2단계에서 한 번에 |
| D4 도크 · 3D 회차 보드 블록 띠 | `screens/office.js` · `office3d/*` | 사무실 떠 있는 무리 정리(3단계) · 3D 재질(4단계)과 같은 파일 |
| D5 `/api/meta`로 이름표 | `lib.js` | 자원 아이콘 키(§3-3)를 같은 계약에 얹으면 한 번에 끝남 — 기술 몫 제안 |

**순서 제안(B4 ①):** P2 2차 합치기 → 1단계(토큰, 화면 모양 그대로라 충돌 적음) → 2단계 → 3단계 → 4단계(캐릭터 재기획과 묶어도 됨). P2 2차가 진행되는 동안 지킬 것 두 가지: **새 색 값을 직접 쓰지 않고 지금 토큰을 쓴다**, **새 이모지 아이콘을 넣지 않는다**(필요하면 글자 + 지금 있는 기호).
